Un buen color se puede apagar en pocas semanas si no se cuida. La mayoría de las veces no es la tintura: es cómo se lava y cuánto calor recibe el pelo.

## 1. Espera antes del primer lavado

Después de teñir, deja pasar dos o tres días antes de lavarte el pelo. Así el color alcanza a asentarse.

## 2. Usa productos para pelo teñido

Un shampoo y un acondicionador para pelo con color limpian con más suavidad. Te podemos recomendar uno según tu tono.

## 3. Lava con agua tibia

El agua muy caliente abre la fibra del pelo y el color se va más rápido. Tibia o fría es mejor.

## 4. Cuida el pelo del calor y del sol

Si usas plancha o secador, aplica antes un protector térmico. En verano, un sombrero o un producto con filtro solar ayuda a que el color no se aclare.

## 5. Retoca a tiempo

Cuando la raíz ya se nota mucho, el contraste hace que todo el color se vea más apagado. Retocar a tiempo mantiene el resultado parejo.
